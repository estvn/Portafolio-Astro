## Resumen

Aplicación web completa para gestionar las citas médicas con los doctores de un hospital oncológico. Está en producción y se puede ver en [oncometro.com](https://oncometro.com). Proyecto realizado como consultor para Zsystems.

## Mi rol

Analista y Desarrollador Fullstack. Levanté los requerimientos, modelé la base de datos y programé el backend.

## Qué construí

- <strong>Modelado de la base de datos</strong> y backend con patrón <strong>MVC</strong>.
- <strong>Sistema de agendamiento de citas médicas, en producción</strong>.
- API REST en PHP vanilla con conexión a MySQL para la lógica del servidor.
- Frontend con JavaScript y Bootstrap, consumiendo los endpoints mediante AJAX.
- Generación de archivos CSV y PDF con información almacenada en la base de datos.

## Arquitectura y decisiones técnicas

- <strong>PHP vanilla con MVC:</strong> una estructura ligera y sin dependencias de framework, con responsabilidades claras entre modelo, vista y controlador.
- <strong>AJAX sobre endpoints REST:</strong> el frontend consume la API sin recargar la página, lo que da una experiencia ágil para agendar y consultar citas.
- <strong>Modelado previo de datos:</strong> definir bien las entidades antes de programar sostiene la lógica de agendamiento.

## Resultados

- Un sistema de agendamiento de citas en producción para un hospital oncológico.
- Información de la aplicación exportable a CSV y PDF.

## Stack

JavaScript, AJAX, Bootstrap, PHP (API REST, MVC), MySQL, Git/GitHub.

## Overview

A complete web application to manage doctor appointments at an oncology hospital. It is in production and can be seen at [oncometro.com](https://oncometro.com). Delivered as a consultant for Zsystems.

## My role

Analyst and Fullstack Developer. I gathered the requirements, modeled the database and wrote the backend.

## What I built

- <strong>Database modeling</strong> and a backend with the <strong>MVC</strong> pattern.
- A <strong>medical appointment scheduling system, in production</strong>.
- A REST API in vanilla PHP connected to MySQL for the server-side logic.
- Frontend with JavaScript and Bootstrap, consuming the endpoints through AJAX.
- CSV and PDF file generation from data stored in the application database.

## Architecture and technical decisions

- <strong>Vanilla PHP with MVC:</strong> a lightweight structure with no framework dependency and clear responsibilities between model, view and controller.
- <strong>AJAX over REST endpoints:</strong> the frontend consumes the API without reloading the page, giving a fluid experience for booking and checking appointments.
- <strong>Upfront data modeling:</strong> defining the entities well before coding supports the scheduling logic.

## Key achievements

- An appointment scheduling system in production for an oncology hospital.
- Application data exportable to CSV and PDF.

## Stack

JavaScript, AJAX, Bootstrap, PHP (REST API, MVC), MySQL, Git/GitHub.
