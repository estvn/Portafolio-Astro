## Contexto

La información del Colegio de Químicos Farmacéuticos de Honduras (CQFH) se encontraba en archivos de Excel. 
El objetivo fue consolidarla en una base de datos para poder consultarla y exponerla al sistema.

## Qué se construyó

- Procesos <strong>ETL con SSIS y Python</strong> para limpiar, transformar y cargar <strong>más de 100 mil registros</strong> desde Excel a la base de datos.
- Objetos de base de datos (<strong>procedimientos almacenados, vistas y funciones</strong>) para consolidar y consultar la información cargada.
- Una <strong>API REST</strong> conectada a la base de datos para exponer la información al sistema.

## Resultados

La información que antes vivía en hojas de cálculo quedó centralizada y disponible para el sistema a través de la API.
