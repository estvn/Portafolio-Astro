Se ha desarrollado una aplicación web completa para la gestión del inventario de un taller Industrial. La aplicación contiene los diferentes
roles (administrador, técnico, cliente) y sus respectivas autorizaciones y autenticaciones para garantizar la seguridad en la visualización 
de datos entre los diferentes roles. Se ha usado Javascript, Bootstrap y jQuery en el FrontEnd, se ha creado una API-REST con PHP y conexión 
con el motor de base de datos MySQL para la lógica en la parte del servidor.

## Aspectos destacados

- <strong>Base de datos normalizada</strong> que garantiza integridad y consistencia de la información de productos, proveedores y movimientos.
- <strong>Control de existencias</strong> con registro de entradas y salidas, y trazabilidad del historial de movimientos por producto.
- <strong>Catálogo de productos</strong> y <strong>alertas de stock mínimo</strong> para anticipar el reabastecimiento.
- <strong>Reportes</strong> de inventario y de movimientos para apoyar el control del taller.
- Levantamiento de requerimientos con el cliente y backend con patrón <strong>MVC</strong>.
