## Resumen

Proyecto personal de backend de punta a punta: migrar un dataset de 20,238 registros a Azure SQL con un pipeline ETL, exponerlo mediante una API REST segura con FastAPI, medir su rendimiento con telemetría y acelerarlo con una caché Redis que se invalida automáticamente. Termina desplegado como contenedor en Azure.

## Logros clave

- <strong>Pipeline ETL con Azure Data Factory</strong> desde un CSV hacia Azure SQL Database (20,238 registros, 6 columnas seleccionadas).
- <strong>Autenticación y autorización</strong> con Firebase y JWT con tiempo de vida; la creación de registros está restringida a usuarios administradores.
- <strong>Caché Redis con invalidación automática</strong>: sin caché las respuestas promediaban unos 18 segundos; con datos en caché las consultas bajaron a entre 1.5 y 2.6 segundos en desarrollo, y a 1.24 s y 878 ms en el despliegue en Azure.
- <strong>Telemetría con Application Insights</strong> (OpenTelemetry) para medir tiempos de respuesta, peticiones, fallos y disponibilidad.
- <strong>Contenedorización con Docker</strong>, imagen publicada en Azure Container Registry y ejecutada en una Web App de Azure.

## Stack

Azure (Data Factory, SQL Database, Cache for Redis, Container Registry, App Service, Application Insights), Terraform, FastAPI, Python, Redis, Firebase, Docker.

## Overview

A personal end-to-end backend project: migrate a dataset of 20,238 records into Azure SQL with an ETL pipeline, expose it through a secure FastAPI REST API, measure its performance with telemetry and speed it up with a Redis cache that invalidates automatically. It ends up deployed as a container on Azure.

## Key achievements

- <strong>ETL pipeline with Azure Data Factory</strong> from a CSV into Azure SQL Database (20,238 records, 6 selected columns).
- <strong>Authentication and authorization</strong> with Firebase and JWT with a limited lifetime; record creation is restricted to admin users.
- <strong>Redis cache with automatic invalidation</strong>: without the cache, responses averaged about 18 seconds; with data in cache, queries dropped to between 1.5 and 2.6 seconds in development, and to 1.24 s and 878 ms in the Azure deployment.
- <strong>Telemetry with Application Insights</strong> (OpenTelemetry) to measure response times, requests, failures and availability.
- <strong>Containerization with Docker</strong>, image published to Azure Container Registry and run on an Azure Web App.

## Stack

Azure (Data Factory, SQL Database, Cache for Redis, Container Registry, App Service, Application Insights), Terraform, FastAPI, Python, Redis, Firebase, Docker.
