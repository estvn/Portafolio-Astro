## Contexto

Sistema para dar seguimiento al trabajo en campo durante la instalación de torres de telecomunicaciones.

## Qué se construyó

- Un gestor de proyectos con <strong>frontend y API REST</strong> bajo <strong>arquitectura hexagonal</strong>.
- Integración con una <strong>API externa de tracking de campo</strong>, cuya data se almacena en una <strong>base de datos normalizada</strong>.
- <strong>Automatización de pruebas y despliegue continuo (CI/CD)</strong>.

## Resultados

La operación en campo quedó registrada en una base de datos consistente, que además alimenta los dashboards de análisis.
