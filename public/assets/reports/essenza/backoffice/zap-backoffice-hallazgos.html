Backoffice: hallazgos de OWASP ZAP, estado "antes"

2026-11-21. ZAP 2.17.0. Build de producción servido con vite preview (localhost:5174). La SPA se recorrió con Playwright pasando por el proxy de ZAP (49 de 49 tests pasan) porque una araña no descubre las rutas de una SPA. Este informe contiene solo las alertas del backoffice.

Resumen. 6 alertas distintas: 3 reales (todas de cabeceras de seguridad) y 3 falsos positivos o informativas. Causa de las 3 reales: la carpeta public/ solo tenía _redirects; no había _headers ni cabeceras en vite.config.ts.

Límites

  • ZAP no analiza el DOM (XSS que React renderice) ni la autorización por rol o tenant.
  • La interfaz es una página estática: el escaneo activo sobre localhost:5174 tuvo pocos puntos de ataque (158 peticiones).
  • Las cabeceras de _headers las aplica Cloudflare Pages; el backoffice corre en Render Static Site, que las ignora. El rescaneo local las ve gracias a preview.headers de vite.config.ts.
  • El reporte completo de ZAP no se publica porque contiene tokens de las cuentas de prueba.
